# タイムビジュライザー (Time Visualizer) ⏳✨

24時間バーチカルスケジュール形式で毎日の行動を可視化し、**「睡眠不足の解消」**と**「自由時間の捻出」**をサポートするPWA対応Webアプリケーションです。

外部ライブラリを一切使わず、**完全なバニラJavaScript・CSS・HTMLによる単一ファイル（Single File）**で構成されています。スマートフォンやPCのブラウザで直接開くだけで即座に動作し、ホーム画面に追加することでネイティブアプリのように利用できます。

---

## 📱 主な機能と特徴

### 1. タイムライン画面（メイン・入力）
* **24時間バーチカル表示（縦方向1ページ・ノースクロール設計）**:
  - 画面の縦スクロールを完全に排除し、利用可能な画面高さいっぱいに24時間タイムラインをレスポンシブ配置。0:00〜24:00の1日の行動が1画面でパノラマ一望可能。
  - **時刻目盛り（2時間刻み）**: 偶数時間（0:00, 2:00, 4:00...24:00）のみ数字を表示し、奇数時間は薄い目盛り線のみを残して視認性とスッキリした余白を両立。
  - **コンパクト・ヘッダー & サマリー**: 上部サマリーカードやショートカットバーの縦幅を約2/3に凝縮し、メインタイムラインの縦表示領域を最大化。
  - 行動ブロックは極小フォントを用いた1行表示（アイコン＋カテゴリ名）でスッキリ配置。
  - タイムライン上のタップ位置から「最も近い30分〜1時間」をスマートに自動選択して登録モーダルを展開。
* **直感的なタップ＆ドラッグ入力**:
  - 空き時間をタップするだけで直感的に時間枠を選択可能。
  - **大カテゴリ1タップ ➔ （生活・自由時間のみ）小カテゴリ1タップ**で即座に記録完了するスムーズなUX。
* **サマリーメーター**: 当日の「睡眠時間」「自由時間」の合計値と達成バッジをリアルタイム表示。
* **ワンタップ・テンプレート**:
  - `💼 平日テンプレート適用`
  - `🏖️ 休日テンプレート適用`
  - `🔄 昨日をコピー`
  - `➕ 予定を手動追加`

### 2. 睡眠分析画面
* **リングプログレス**: 目標睡眠時間（例: 7.5時間、0.5h単位で調整可能）に対する当日の達成率をSVGリングで直感的に可視化。
* **直近7日間の睡眠負債（バジェット）カード**:
  - 週間目標時間と実績時間の差分から「睡眠負債（例: -3.5h）」を自動算出。
  - 現在の負債状況に応じた具体的な生活アドバイスを表示。
* **就寝・起床リズムの安定性グラフ**: 直近7日間の就寝時刻・起床時刻のブレを可視化し、体内時計（サーカディアンリズム）の一貫性をサポート。

### 3. 集計レポート画面（ヒートマップ & データ管理）
* **カテゴリ切り替え**: ［🌙 睡眠時間］［✨ 自由時間］［🌈 全体（全行動）］
* **3つのビジュアライザー**:
  1. **週間マトリックス（縦軸: 7日間 × 横軸: 24時間）**:
     - スマホ画面幅に24時間が横スクロールなしでぴったり収まるレスポンシブ配置。
     - 上部に主要時刻目盛り（0, 6, 12, 18, 23時）を視認性高く表示。
     - 各セルタップで行動詳細（時間帯・カテゴリ・メモ）をトースト表示。
     - 左端の日付ラベルタップで、その日のタイムライン画面へ即座にジャンプ可能。
  2. **月間カレンダー（縦スクロールなし・1画面フィット）**:
     - 端末の表示可能高さを自動検知し、7曜日×日付セルが1画面内に均等伸縮してジャストフィット。
     - 時間の長さに応じた4段階のカラー濃淡と数値を表示（日付タップでその日のタイムラインへ移動）。
  3. **年間ヒートマップ（横スクロールなし・100%幅ジャストフィット）**:
     - GitHubのコントリビューショングラフ風（52週×7日）の配列を維持しながら、横スクロールを完全排除してスマホ幅に100%フィット。
     - マスをタップ・ホバーすると日付と実績時間がダイナミック表示され、タップでその日のタイムラインへジャンプ。
     - 下部に「記録日数」「年間合計時間」「1日平均時間」のサマリースタッツをリアルタイム表示。
* **💾 データバックアップ & 復元（JSONエクスポート / インポート）**:
  - 「週間マトリクス」タブ下部に配置され、月間・年間閲覧時は非表示化されて1画面表示の視認性を最大化。
  - **エクスポート（書き出し）**: 全日程の行動記録データおよび目標睡眠設定を日付スタンプ付きJSONファイル（`time-visualizer-backup-YYYYMMDD.json`）としてワンクリック保存・ダウンロード。
  - **インポート（読み込み）**: 保存したバックアップJSONファイルを選択すると、記録日数・イベント総数などのプレビューを確認した上で復元可能。
  - **選べる復元モード**:
    - **「統合して復元」**: 端末内の既存データを残しつつ、ファイル内の日程データを取り込み・更新（日々の追記・マージに最適）。
    - **「完全上書き復元」**: 端末のデータを一度初期化し、ファイルの内容で完全に置き換え。

### 4. PWA対応 & オフライン動作
* Web App Manifest およびアプリアイコン（SVG）を Data URI としてインライン埋め込み。
* インライン Service Worker を搭載。
* `localStorage` を使用した完全クライアントサイドのデータ永続化（ブラウザを閉じてもデータが保持されます）。
* 初回起動時に直近14日分のリアルなサンプルデータを自動生成するため、起動直後からすべての機能・グラフを体験可能。

## 🚀 使い方・起動方法

### ローカルで直接開く
特別なビルド環境やパッケージマネージャーは不要です。
1. 本リポジトリの `index.html` をお好みのWebブラウザ（Chrome, Safari, Edgeなど）でダブルクリックして開きます。

### 簡易Webサーバーで起動する場合
スマートフォン実機からアクセスしたり、PWA機能をフルに検証する場合はローカルサーバーをご利用ください。

```bash
# Python 3 を使う場合
python -m http.server 8000

# または Node.js (npx) を使う場合
npx serve .
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。

### スマートフォンでPWAとしてインストール
* **iOS (Safari)**:
  画面下部の共有ボタン（四角から矢印が出ているアイコン） ➔ **「ホーム画面に追加」** をタップ。
* **Android (Chrome)**:
  右上のメニューアイコン ➔ **「アプリをインストール」** または **「ホーム画面に追加」** をタップ。

ホーム画面から起動すると、アドレスバーやブラウザUIのない全画面アプリとして快適にご利用いただけます。
